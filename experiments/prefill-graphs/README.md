# Prefill 图原型

本分支记录两个独立实验。它们均以 910B4-1 和 vLLM-Ascend 0.30.0 为基线。

- **混合图加 EX。** `hybrid-ex/` 保存只在隔离环境启用的非 Triton 子图编译补丁。17 个子图可复用编译产物，Prefill 实际运行分段图，解码运行整图。单卡 2K、64 并发的混合图吞吐为 376.56 → 377.19 tok/s，约 +0.17%。
- **固定 Prefill 块的整图回放。** `fixed-prefill/` 保存 8,064-token 块的回放和 GDN 动态元数据更新原型。单卡 8K 和 32K 的 TTFT 变化约 0.15% 和 0.20%。全量试验完成 156／196 个对照点，TP2/MTP2 在混合续算的贪心输出校验中失败。

两个目录分别提供针对官方标签的补丁和实验辅助模块。复查时应独立启用，每次只加载一种 overlay。前者通过 `EX_STAGE` 和 `GRAPH_TREND_DIR` 配置，后者通过 `FIXED_GRAPH_DIR` 配置。结果仅适用于实测形状和部署组合。
