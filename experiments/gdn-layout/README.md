# GDN 布局复用与状态转置融合

基线为 910B4-1、Qwen 27B W8A8、TP1/MTP0、vLLM-Ascend 0.30.0。该目录保存隔离实验的 GDN 补丁和辅助算子。期望从已有头优先布局复用 QKV，并减少状态读写与转置之间的中间数据搬移。

| 配置 | 8K 单并发 TTFT 中位 | 2K 并发 64 输出吞吐 |
| --- | ---: | ---: |
| 原始布局 | 1.595 秒 | 390.65 tok/s |
| QKV 布局复用 | 1.551 秒 | 397.85 tok/s |
| 布局复用加状态转置融合 | 1.547 秒 | 398.26 tok/s |

零前缀命中，输出 256 token。检查首段、续算和多槽位状态。相对于布局复用，额外融合的收益很小。独立的 MegaGDN 回放在修正求逆分块后通过数值复核，8064-token 形状仍慢于原版 FLA，未做服务级集成。

补丁以隔离运行保存。复现时，把辅助模块放在 Python 搜索路径，按照补丁中的 `LAYOUT_ARM` 条件选择 B 或 C，将其与原始 A 对照。`git apply --check experiments/gdn-layout/gdn_screen_copy.patch` 可检查补丁与本标签的兼容性。
